The HTML DOM Tree of Objects

Finding/Accessing HTML Elements

The HTML DOM can be used to access HTML elements. When you want to access HTML elements with JavaScript, you have to find the elements first. There are a couple of ways to do this:

  • Finding HTML elements by id
  • Finding HTML elements by tag name
  • Finding HTML elements by class name
  • Finding HTML elements by CSS selectors
  • Finding HTML elements by HTML object collections

The getElementById method used id="demo" to find an element. id="demo" is an HTML property. getElementById() is a DOM Method. innerHTML is a DOM Property.
