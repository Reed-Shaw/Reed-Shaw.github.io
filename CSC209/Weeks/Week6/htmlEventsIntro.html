JavaScript Event Handlers

An event handler is JavaScript code that runs when an event happens.

They can be used to handle and verify user input, user actions, and browser actions.

Ex. things that should be done every time a page loads, things that should be done when a page is closed, action that should be performed when a user clicks a button, content that should be verified when a user inputs data, etc.
