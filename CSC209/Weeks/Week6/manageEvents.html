Manage Events Lab

Event Management is about adding, removing, and controlling events.

Adding Events

Example of adding an event listener that uses a function. When the button is clicked, a listener will call the function "addEvent()" which will change the text of the button to "Clicked!".

Removing Events

In this example, when the "add" button is pressed, an event listener which adds an event listener to perform "myFunction()" to the "test" button will fire. When the "remove" button is pressed, an event listener which removes the event listener that performs "myFunction()" from the "test" button will fire. When the "test" button is clicked, it will perform "myFunction()" which will print "Hello World!" if the event listener has been added, and do dothing if the even listener has been removed/was never added.

Note: To remove an event listener, you must use the same named function you used to add it.

Blocking Events

In this example, there is an event listener attached to the link so that when it is clicked, the default action of the link is blocked using "event.preventDefault()" so that instead of opening the link, the message "That link has been blocked!" is displayed.
