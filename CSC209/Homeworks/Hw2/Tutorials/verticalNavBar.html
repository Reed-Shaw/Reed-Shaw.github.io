CSS Navigation Bars

A navigation bar is an important component of web design. Navigation bars helps users to easily navigate between different sections of a website. Navigation bars are typically built with HTML list elements ( <ul> and <li>), and then styled with CSS to get a great look.A navigation bar is typically located at the top or at the side of a webpage.

Vertical Navbar

This responsive NavBar has a gray background color, and the background color and the text color of the links changes when the user mouses over them. The "home" tab is labeled "active". The links are also centered and we've given the list a border. Also, the bar is full-hieght, or "sticky". Changing the size of the browser window will change the placement of the navbar.
