This is an inline span Hello World! element inside a paragraph. The span element is a inline-level element. It will not start on a new line and only takes up as much width as necessary.


Div Element

The div element is often used as a container for other HTML elements. It has no required attributes, but style, class, and id are common. When used together with CSS, the div element can be used to style blocks of content like this one.


The span element is used to mark up part of a text, or part of a document. The span element has no required attributes, but style, class, and id are common. When used together with CSS, the span element can be used to style parts of text.
