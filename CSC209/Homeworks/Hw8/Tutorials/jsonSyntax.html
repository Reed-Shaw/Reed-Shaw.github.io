JSON Syntax Tutorial

JSON has a very simple syntax for representing structured data. One JSON document consists of one JSON value.

The value can be:

  • An Object
  • An Array
  • A String
  • A Number
  • A Boolean
  • or null

JSON Object Literals

This is a JSON string:

'{"name":"John", "age":30, "car":null}'

Inside the JSON string there is a JSON object literal:

{"name":"John", "age":30, "car":null}

A JSON object is written between curly braces { }. An object contains zero or more properties. Properties come in key/value pairs separated by commas. key names are strings enclosed in double quotes. Keys and values are separated by a colon.

Values must be a valid JSON data type. JSON supports the above listed data types.

JSON Array Literals

This is a JSON string:

'["Ford", "BMW", "Fiat"]'

Inside the JSON string there is a JSON array literal:

["Ford", "BMW", "Fiat"]

A JSON array is written between square brackets [ ]. An array contains zero or more values. Values are separated by commas. Values can be any of the six JSON data types.

JSON Property Names

Every property name must be a string. Property names must be enclosed in double quotes.

Valid:

'{"name":"John"}'

Invalid:

'{name:"John"}'

JSON Strings

JSON strings must use double quotes.

Valid:

'{"name":"John"}'

Invalid:

'{"name":'John'}'
