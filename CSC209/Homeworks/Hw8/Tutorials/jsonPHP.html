JavaScript Loading JSON

JavaScript can load JSON and convert it into JavaScript values. The modern way to load JSON is with the fetch() method.

Loading JSON

Use the fetch() method to request the JSON file. The response.json() method parses the JSON text and returns a JavaScript value.

async function loadJSON() { const response = await fetch("customer.json"); const customer = await response.json(); myDisplayer(customer.name); } loadJSON();

Note: If the file contains a JSON array, response.json() returns a JavaScript array.
