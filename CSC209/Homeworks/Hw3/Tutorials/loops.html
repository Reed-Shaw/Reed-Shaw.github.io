The For Loop

Syntax:

The for statement creates a loop with 3 optional expressions:

for (expr1; expr2; expr3) {
// code block to be executed
}

expr1 is executed one time before the execution of the code block.

  • expr1 is used to initialize the variable(s) used in the loop (let i = 0). expr1 is optional. You can omit expr1 if the value is set before the loop starts (and you don't mind what it's value is already).
expr2 defines the condition for executing the code block.
  • expr2 is used to evaluate the condition of the initial variable (i < len). expr2 is also optional. If expr2 returns false, the loop will end.
  • NOTE: If you omit exp 2, you must provide a break inside the loop. Otherwise the loop will never end. This will crash your browser.
exp3 is executed every time the code block has been executed.

  • exp3 increments the value of the initial variable (i++). expr3 is optional. expr3 can do anything like negative increment (i--), positive increment (i = i + 15), or anything else. expr3 can be omitted (if you increment the value inside the loop)

The While Loop

The while loop loops through a block of code as long as a specified condition is true.

Syntax:

while (condition) {
// code block to be executed
}

The Do While Loop

The do while loop is a variant of the while loop. The do while loop will execute the code block once, before checking if the condition is true, then it will repeat the loop as long as the condition is true.

Syntax:

do {
// code block to be executed
}
while (condition);

The do while runs at least once, even if the condition is false from the start. This is because the code block is executed before the condition is tested.

Break in Loops

When break is encountered in a loop, the loop terminates immediately. The program control is transfered to the statements following the loop. No more loop iterations are executed.

Labed Break

JavaScript can use label break statements to exits a loop or block and transfers the control to the labeled statement. The break statement is particularly useful for breaking out of inner or outer loops from nested loops.

Note: break and continue are the only JavaScript statements that can "jump out of" a code block. (A code block is a block of code between { and }).

Without a label reference, break can only jump out of a loop or a switch.

With a label reference, break can jump out of any code block
