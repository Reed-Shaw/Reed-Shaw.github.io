JavaScript Arithmetic Operators

Arithmetic Operators are used to perform arithmetic on numbers:

A typical arithmetic operation takes two numbers (or expressions) and produces a new number.

Here we made a paragraph with an id, initialize two variables with "let a = 3;" and "let x = (100+50) * a;" and then change the html of the paragraph to display x.

Operators include:

Operator Description
+ addition
- subtraction
* multiplication
** exponentiation
/ division
% modulus (remainder from division)
++ increment
-- decrement

Adding Strings and Numbers

Adding two numbers, will return the sum as a number like 5 + 5 = 10. Adding a number and a string, will return the sum as a concatenated string like 5 + "5" = "55".

Here we have a paragraph with an id, and initialized three variables; one containing the number 5, one containing a concatination of a string containing "5" and a number 5, and one containing a the word "Hello" concatinated with the number 5. The paragraph html is changed to display each of on a new line.

Addition Assignment Operator

The Addition Assignment Operator (+=) adds a value to a variable.

Here we have a paragraph with an id, and initialized one variable (n1) containing the number 10. We then write 'n1 += 5;'' to add 5 to the value n1 already holds. The paragraph html is changed to display n1.

NOTE: The (+=) operator can both concatinate strings and add value to a variable.

NOTE: other operator symbols (-=, *=, /=, **=, %=, etc) work in the same way.

Comparison Operators

Comparison operators are used to compare two values. Comparison operators always return true or false.

The > (greater than) Operator

Assign 5 to myNum, and display the value of the comparison (myNum > 8).

Operator Description
== equal to
=== equal value and equal type
!= not equal
!== not equal value or not equal type
> greater than
< less than
>= greater than or equal to
<= less than or equal to
